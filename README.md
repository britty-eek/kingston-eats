# kingston-eats
Kingston-Eats is a food discovery website featuring restaurants or vendors, categories, and reservation requests.

## Project concept and planning
- Audience: The audience for Kingston Eats is people who live in or near the Kingston area who are interested in finding restaurant spots to eat.
- Purpose: The purpose of this website is to help people discover restaurants by food type, see what is open, and request a table.
- Design: a calm, photo-led layout with cream and charcoal tones, serif headings, and one muted green accent, inspired by the look and feel of kingrestaurant.nyc and https://www.commanderspalace.com/.
- Page plan: a home page to introduce the site, a restaurants page to explore the full list, and a reservation page for table requests.

## Pages
- The Home page (index.html) is used for photos, introduction, about text, featured restaurants with filters and details.
- The Restaurants page (restaurants.html) is used for the full list of all the restaurants connected to Kingston Eats.
- The Reserve page (reserve.html) is used for the reservation form for people making a reservation online.

- ## Technologies
HTML5, CSS3, Bootstrap 5.3.8, JavaScript and jQuery 4.0.0.

## Bootstrap components used
Responsive navbar, containers and grid, cards, buttons, form controls, spacing and responsive utilities, plus four Bootstrap JavaScript components: Collapse (mobile menu and contact card), Modal (restaurant details), Carousel (home page slideshow) and Toast (reservation confirmation).
